# 🔌 USART 8251 Serial Communication Simulator

## 📌 Overview
A simulation of serial communication using 8251 USART to demonstrate data transmission between systems.

## 🎯 Objective
To understand how serial communication works in microprocessor systems.

## 🛠️ Technologies Used
- Python

## ⚙️ Features
- Data transmission simulation
- Receive and display data
- Configurable mode, parity, and stop bits

## 🧩 How It Works
- User inputs data
- System simulates transmission
- Data is received and displayed

## ▶️ How to Run
python usart_simulator.py

## 📚 Concepts Used
- Serial Communication
- USART
- Data Transmission
